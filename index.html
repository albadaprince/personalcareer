Connecting Firebase

Right now this page is running in local mode.

To sync across devices, create a free Firebase project, enable Firestore and Authentication, then copy your web config into firebase-config.js beside this file. Full steps are in the README.

Firebase needs a real server. Opening this file directly from your hard drive (file://) blocks the module loader, so it will always fall back to local mode. Use GitHub Pages, Netlify, or run python3 -m http.server in the folder.
